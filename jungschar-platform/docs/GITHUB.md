# GitHub

Dieses Projekt wurde wegen fehlender Repo-Create-Rechte vorübergehend als Branch
im eCamp3-Fork veröffentlicht:

https://github.com/xelarettusander-dot/ecamp3/tree/cursor/jungschar-platform-scaffold-627f

## Eigenes Repo anlegen (empfohlen)

1. Auf GitHub leeres Repo erstellen: `xelarettusander-dot/jungschar-platform`
2. Danach:

```bash
git remote set-url origin https://github.com/xelarettusander-dot/jungschar-platform.git
git push -u origin main
```

Diesen Branch **nicht** nach `ecamp3/devel` mergen.
