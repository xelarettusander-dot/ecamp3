# Im eCamp3-Workspace

Dieser Ordner enthält die **Jungschar Planungsplattform**.

```bash
cd jungschar-platform
cp .env.example .env   # falls noch nicht vorhanden
npm install
npm run dev            # http://localhost:3000
```

Bestehende eCamp-/Notfallblatt-Produktivsysteme werden nicht verändert.
